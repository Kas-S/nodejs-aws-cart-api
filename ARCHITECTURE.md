## Data Flow

```
1. User Request
   └─> API Gateway
       └─> Lambda Function (in VPC)
           ├─> Reads DB credentials from Secrets Manager
           ├─> Connects to RDS PostgreSQL
           │   ├─> Query database
           │   └─> Get results
           └─> Returns response to API Gateway
               └─> Response to User
```

## Free Tier Resource Limits

| Resource             | Free Tier Limit    | Current Usage     |
| -------------------- | ------------------ | ----------------- |
| RDS Instance Hours   | 750 hours/month    | ~720 hours (24/7) |
| RDS Storage          | 20 GB              | 20 GB             |
| RDS Backups          | 20 GB              | Auto (7 days)     |
| Lambda Requests      | 1M/month           | Varies            |
| Lambda Duration      | 400,000 GB-seconds | Varies            |
| API Gateway Requests | 1M/month           | Varies            |

## Component Responsibilities

### API Gateway

- Public HTTPS endpoint
- Routes requests to Lambda
- Handles CORS
- Request/Response transformation

### Lambda Function

- Runs NestJS application
- Handles HTTP requests
- Connects to RDS database
- Retrieves credentials from Secrets Manager
- Returns responses

### RDS PostgreSQL

- Persistent data storage
- Handles SQL queries
- Automatic backups (7 days)
- Private network access only

### Secrets Manager

- Stores database credentials securely
- Automatic encryption at rest
- IAM-based access control
- Automatic rotation (optional)

### VPC & Security Groups

- Network isolation
- Access control between resources
- Private subnet for database security
- No public internet access to database

## Deployment Order

1. VPC & Subnets
2. Internet Gateway & Route Tables
3. Security Groups
4. RDS PostgreSQL Instance (~10-15 min)
5. Secrets Manager Secret
6. Lambda Function
7. API Gateway
8. Outputs & Integration

Total Deployment Time: ~15-20 minutes
